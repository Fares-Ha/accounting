# User Interface

This directory contains the user interface components of the application, organized into the following widgets:

*   `category_widget.py`: A widget for managing product categories.
*   `chart_of_accounts_widget.py`: A widget for managing the chart of accounts.
*   `customer_dialog.py`: A dialog for adding and editing customers.
*   `customer_widget.py`: A widget for managing customers.
*   `ledger_widget.py`: A widget for managing journal entries.
*   `login_window.py`: The login window for the application.
*   `main_window.py`: The main application window.
*   `notification_widget.py`: A widget for displaying notifications.
*   `product_widget.py`: A widget for managing products.
*   `purchase_widget.py`: A widget for managing purchase orders.
*   `reporting_widget.py`: A widget for displaying reports.
*   `sales_order_detail_dialog.py`: A dialog for viewing the details of a sales order.
*   `sales_widget.py`: A widget for managing sales orders.
*   `supplier_dialog.py`: A dialog for adding and editing suppliers.
*   `supplier_widget.py`: A widget for managing suppliers.
