# Core Services

This directory contains the business logic of the application, organized into the following services:

*   `accounting_service.py`: Handles the core accounting logic, including creating and managing accounts and journal entries.
*   `auth.py`: Handles user authentication.
*   `category_service.py`: Handles the business logic for product categories.
*   `customer_service.py`: Handles the business logic for customers.
*   `export_service.py`: Handles exporting data to PDF and Excel.
*   `notification_service.py`: Handles generating notifications.
*   `product_service.py`: Handles the business logic for products.
*   `purchase_service.py`: Handles the business logic for purchase orders.
*   `reporting_service.py`: Handles generating reports.
*   `sales_service.py`: Handles the business logic for sales orders.
*   `supplier_service.py`: Handles the business logic for suppliers.
